# 📚 ShelfWise - Library Management System

ShelfWise is a full-stack MERN Library Management System developed to simplify library operations for both students and administrators.

## 🚀 Features

### 👨‍🎓 Student
- User Registration with OTP Verification
- Secure Login using JWT Authentication
- Complete & Update Profile
- View Issued Books
- View Fine Details
- Dashboard

### 👨‍💼 Admin
- Secure Admin Login
- Add, Update & Delete Books
- Issue & Return Books
- Manage Students
- Fine Management
- Dashboard

## 🛠 Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- Nodemailer
- Tailwind CSS

## 📂 Project Structure

```
backend/
frontend/
```

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/ankitsaini06/ShelfWise-Library-Management-System.git
```

### Backend

```bash
cd backend
npm install
npm run server
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## 🔐 Environment Variables

Create a `.env` file inside the backend folder.

```
PORT=
MONGO_URI=
JWT_SECRET=
EMAIL_USER=
EMAIL_PASS=
```
